# Sea 使用说明

> 写给第一次打开它的人。看完这一页，你就知道每个按钮是干什么的、数据存在哪、以及哪些事**不该**拿它干。
> 不需要先读别的文档。

---

## 0. 这是个什么东西

一句话：**一个用「海域」比喻个人长期状态的工作台**。

它跟待办清单的区别在于**问的问题不一样**：

| 待办工具问 | Sea 问 |
|---|---|
| 你今天要做什么 | 你这周偏航了吗 |
| 这件事做完了吗 | 这张卡多久没动了 |
| 你有多少任务 | 你这个月产出了什么 |

所以它的首屏不是「今天的清单」，是**五个域的状态**（职业 / 财务 / 健康 / 成长 / 基础）+ 一句你自己写下的一年后的取舍标准（叫「北极星」）。

**它不是**：不是日程软件（不用来管会议）、不是笔记软件、不是财务记账专用工具（只做个人流水的轻量记录）、不是多人协作工具。

---

## 1. 打开它

它是一个**单文件网页**，没有任何依赖：

```bash
# 最省事：双击 Sea-2.8.html
# 推荐（localStorage 行为更接近真实环境）：
python -m http.server 8080
# 然后浏览器打开 http://localhost:8080/Sea-2.8.html
```

浏览器用 **Edge 或 Chrome**。Firefox 能用，但「存档文件」功能会自动退化成只有浏览器存储；手机能打开，但拖拽体验一般（见 §7）。

---

## 2. 第一眼：空白盘

首次打开是**完全空白的**——没有示例数据，没有别人的生活。

每个空区域都带一句提示，格式统一是「**还没有 X · 点哪里做 Y**」，比如：

- 岛屿卡池：`还没有岛屿卡 · 点上面的「+」立一个目标`
- 航行卡池：`还没有航行卡 · 点上面的「+」记一件要做的事`
- 航线池：`还没有航线 · 点上面的「+」建第一条`

**空盘是正常状态，不是坏了。**你看到的所有 0 都是真实的 0。

## 3. 六个术语，一次讲清

整套界面用航海词，但**底下就是六种东西**。搞混它们是最常见的困惑来源：

| 界面叫 | 实际是什么 | 有几点要注意 |
|---|---|---|
| **海域** | 五个领域：职业 / 财务 / 健康 / 成长 / 基础 | 颜色不代表海域（颜色留给稀有度了），只靠文字认 |
| **岛屿卡** | **目标**。一个有名字、有截止日的长期事项 | 达成后**不会消失**，会变成成就卡进秘宝 |
| **航行卡** | **这周要做的一件事**。最小单位，通常 15–60 分钟 | 卡池里的卡**没有「完成」这回事**，只有排进日历后才有 |
| **航线** | 一组卡的**重复安排模板**。按星期循环，或指定几个日期 | 只影响你排入的那一周；完成状态不写回航线 |
| **稀有度** | 五档颜色：绿 → 蓝 → 紫 → 红 → 金 | 只决定边框颜色和竖条数量，**不参与任何计算**，也不代表优先级 |
| **秘宝** | 攒下来的东西：成就 / 影音 / 作品 | 只归档不删除。这是「我做过什么」的唯一凭证 |

三条补充规则：

1. **岛屿卡有三种类型**：讨伐（有死线，必须做完）/ 修行（没有终点，长期重复）/ 铸造（有明确产出物）。选哪个不影响功能，影响你怎么理解它。
2. **一张岛屿卡可以绑定很多航行卡**。航行卡勾完成时，会刷新那张岛屿卡的「最后活动日」——这是「抛锚检测」唯一的数据来源。
3. **成长海域的航行卡勾完成后会自动落一条投入流水**（不用手记）。其他海域的不会。

## 4. 第一个 10 分钟：跑通一个最小闭环

不要一上来就填满八个页面。**先跑通一次完整的循环**，你会立刻明白它是怎么运作的：

1. **船舵 → 北极星**：写一句话。例：`2027 年 6 月前，拿到四大或外资所的审计 offer。`
   不用写得漂亮，这个框随时能改，历史版本留在「历史记录」里。
2. **航行 → 岛屿卡池 → `+`**：立一个目标。
   名字随便写，海域选「职业」，类型选「讨伐」，截止日写一个真实的日期，稀有度选「蓝」。
3. **航行 → 航行卡池 → `+`**：记一件今天能做的事。
   例：`改一版简历，投 3 家`。目标岛屿选上一步那张卡，预计时长填 40。
4. **把航行卡拖到日历上**：拖到本周任意一格的空白处。
5. **双击那张日程卡**：打完勾，它变成完成态。此时回船舵，「今日航行」里会有它。
6. **右键岛屿卡 → 标记达成**：它会带着同样的边框颜色进「秘宝 → 成就栏」。
7. **看「成长」页**：如果你是成长海域的卡，投入流水里会多一条。

到这一步你已经用过：北极星、目标、任务、排期、完成、成就、流水。剩下六个页面都是这套东西的不同视角。

## 5. 八个页面逐页说明

左侧导航从上到下：**船舵 / 航行 / 秘宝 / 职业 / 财务 / 健康 / 成长 / 复盘**。

### 5.1 船舵（首屏）

一眼判断「哪一域在偏航」。从上到下七块：

| 区块 | 读什么 |
|---|---|
| **北极星** | 你写的那句话。点文字可改；右上「历史记录」看历次版本 |
| **当前聚焦** | 只显示一张岛屿卡——你现在真正在推的那个。卡上有「更换」，点开从全部未完成岛屿卡里选，或当场新建 |
| **仪表盘** | 五个海域各一格，每格一个主数字（职业=真实时薪 / 健康=本周训练天数 / 财务=本周可用额度…） |
| **潮汐情况** | 最近一次复盘是什么时候、隔了多久 |
| **今日航行** | 今天排在日历上的卡，可以直接勾 |
| **偏航预警** | 抛锚的卡（连续 4 周没活动）、超期未达成的卡、该复盘的提示 |
| **最近痕迹** | 本月新增秘宝 + 近三日排期 |

**用法**：每天只打开这一页就够了。它不催你，只告诉你哪里在偏。

### 5.2 航行（核心页面，值得单独读一遍）

页面分三块：**上面 = 航线池（左，固定窄栏）+ 航行日程（右，日历）**；**下面 = 岛屿卡池 + 航行卡池**。

#### 日历

- 周视图，周一到周日，**每天 10 格**。
- 顶部能选年、选月；点中间的周标签（`10.26 – 11.01` 这种）弹出**月历总览**，点某天直接跳过去。
- `‹ 上周` / `今天` / `下周 ›` 翻周。

#### 拖拽语义（这是最容易搞错的地方，一张表说清）

| 你从哪拖 | 拖到哪 | 结果 |
|---|---|---|
| **航行卡**（卡池） | 某一格 | 排进那天的那个位置 |
| **岛屿卡**（卡池） | 日期列（整列） | 给这天设「目标岛屿」标记（一天只允许一张） |
| **专线航线**（航线池） | 日期列 | 排入这一天。**可以拖多天**；再拖一次已排的那天 = 取消 |
| **环线航线**（航线池） | 任意一列 | 整周排入（按它设定的星期）。只有这一周有效 |
| **航线里的日程卡**（弹窗内） | 别的格 | 两格对调 |
| **同上 + 按住 Alt** | 别的格 | **复制**（源格保留） |

> 拖航线时日程格子**不会有落位动效**，这是刻意的：落点本身就是语义，加了动效反而误导。环线落位会有命中高亮。

#### 右键菜单（五套，按你点在哪决定）

| 点在哪 | 菜单内容 |
|---|---|
| **日期列**（表头） | 清空航行 / 目标岛屿设置（= 管理这一天的岛屿卡标记） |
| **空的日程格** | ＋ 新建航行卡并排入 / 从卡池选一张排入（底部还带上面那两项） |
| **日程上的卡** | 标记完成 / 修改这张卡 / 取消这次安排 |
| **岛屿卡池里的卡** | 编辑 / 标记达成 / 删除 |
| **航线卡** | 编辑航线 / 清除全部排期（专线）或 排入本周·取消本周排期（环线）/ 删除航线 |

注意两个「删除」的区别：
- 日程上「**取消这次安排**」= 卡回卡池，卡本身还在。
- 卡池里「**删除**」= 真的删掉这张卡。

#### 航线（重复安排）

航线解决的是「每周三都要练腿」这类事，**不是**用来批量生成一堆卡的。

- **专线**：手工指定几个具体日期（可以多天），深蓝色。
- **环线**：指定星期几，排入某一周时整周生效，天空蓝。**只作用被排入的那一周**，不是永久循环。
- 航线设置弹窗是三栏：左=日程卡池（可 `+` 或右键改删），中=10 格安排（可拖拽换位、Alt 拖复制、右键删除），右=名称/航班类型/循环日期/说明。
- 弹窗里改的都是草稿，**点保存才生效**。
- 航线铺到日历上的卡（派生卡）**可以单独拖、单独删、单独打勾**，而且**只影响那一次**——不会改航线本身。

#### 卡池

- 两个卡池都支持横向拖动翻页（按住空白处拖）、右键菜单、`+` 新建。
- 岛屿卡右键里的「标记达成」= 发一张成就卡进秘宝，**原卡不消失**（它要留着算兑现率）。

### 5.3 秘宝（成就 / 影音 / 作品）

- 左边一列统计：成就·影音·作品三个计数、按月产出、稀有度分布。
- 右边三层陈列：**成就栏**（各域成就卡汇总）→ **影音栏**（书/电影/剧集/番剧/纪录片/游戏/音乐）→ **作品区**（自己产出物：文 / 图 / 视 / 数）。
- 影音字段：封面（点击或拖入图片，自动压缩）、条目名、载体、观看时间、**评星 1–5 星（整数）**、一句话短评（可选）。
- 三种卡都能「观赏」：点卡片进 3D 展柜，拖动可转视角。
- **成就卡的金卡可以自己设，但必须上传凭证**（图片会压到最长边 1400px，非图片 ≤1MB）。没有凭证的金卡不给存。
- **同一件事只记一处**。不要成就栏记一遍、影音栏再记一遍。

`+` 按钮在每一层的标题右侧。

### 5.4 职业

分两块：

**① 薪资推演**（这是本页最耐用的功能）
点「推演记录」填八个参数，它会算出**名义时薪**和**真实时薪**：

```
真实时薪 = (到手月薪 × 发薪月数 ÷ 12 − 每月工作成本)
          ÷ ((在场时间 + 通勤 + 加班) × 每月工作日)
```

四个容易填错的地方，填错就高估：
- 月薪用**税后**，不是 offer 上的税前；
- 减掉**为上班花的钱**（通勤 / 外卖 / 穿搭）；
- 在场时间**含午休**；
- 每月工作日**自己填**，别套 21.75。

右侧三个滑块（通勤变化 / 加班变化 / 涨薪幅度）是**假设推演**，不写进记录，用来比较「哪个 offer 更值」。

**② 档案**：基本档案 + 角色（每个角色下有简历 / 项目 / 成就三栏）。右键角色可删，`+ 新增角色`。这部分是「永驻档案」，旧履历不要删——删了就查不到、也算不出兑现率。

### 5.5 财务

**记一笔**在左上（支出/收入/类别/金额/日期，草稿自动保存）。仪表盘四个数字：本周可用额度、本月结余率、储蓄率、本月已消费。

- **本周可用额度 = 本月剩余预算 ÷ 本月剩余周数**。这是唯一该天天看的数字。
- **导入账单**：粘贴微信账单 CSV 文本，或直接上传 `.csv`/`.txt`（自动识别 UTF-8/GBK）。它会先出预览：识别到几笔、自动归类几笔、多少笔进「未分类」、有没有和已有流水重复。**确认后才真正导入**。
- 归不进已知类别的不会瞎猜，统一进**待分类队列**，你在那里一张张指派。
- **分类映射表**是这个页面唯一越用越值钱的东西：每指派一次，下次同类商户就自动归好。

### 5.6 健康

- **记录身体指标**：身高 / 体重 / 体脂 / 上臂围 / 腰围 / 臀围 + 日期。
- 仪表盘：本周训练 X / Y 天、体重、BMI、腰臂比 + 趋势。
- **训练数据不在这里单独记**——它读的就是航行里的训练卡（带「推/拉/腿/其他」部位的航行卡，或健康海域的卡）。所以在航行里排一次训练、勾掉，这里的热力图就亮了。
- 「新增训练」的 `+` 是快捷方式，建的仍是一张航行卡。

### 5.7 成长

- **记一笔投入**：日期 / 时长（分钟）/ 内容 / 目标岛屿。
- 但更常见的用法是**不手记**：成长海域的航行卡勾完成后自动入账。
- 仪表盘：本周投入时长、连续在轨天数、探索进度、未分类条数。
- 「待归类投入」= 没挂目标岛屿的那些，指派给某张岛才算进它的探索进度。

### 5.8 复盘

四档节奏，**用时不同、问题不同**：

| 档 | 建议时长 | 问什么（节选） |
|---|---|---|
| 日 | 5 分钟 | 今天有卡落地吗 / 有要补回的吗 / 明天第一件事 |
| 周 | 30 分钟 | 哪些卡动了、哪些一次没动 / 有卡抛锚吗 / 下周哪几件占格子 / 财务额度够吗 |
| 月 | 1 小时 | **这个月我产出了什么** / 四域数字哪些在动 / 结余率储蓄率 / 围度重测了吗 |
| 季 | 2 小时 | 主线域要不要换 / 哪些卡该关 / 履历体检 / 哪个部件从没用过，删掉它 |

上面有「自动摘要」——把你这一周期的活动事实先摆出来（完成了几张卡、投入多久、花了多少），**你看着数据回答，不是凭空回忆**。

月度那一问「这个月我产出了什么」是全系统最狠的一句：列不出来，说明这个月只有输入没有输出。

## 6. 数据在哪、怎么备份、怎么搬家

**默认不生成任何文件**，全部写进浏览器的 `localStorage`（按站点隔离）。

| 位置 | 存什么 |
|---|---|
| `sea_workspace_v1` | 主数据（目标、卡、流水、统计），约 10KB。**唯一真源** |
| `sea_assets_v1` | 附件（封面、简历、凭证），base64 编码 |
| `sea_snap_main` / `sea_snap_assets` | 每次启动前的本机快照，出事能捞一把 |
| IndexedDB `sea_file_db` | 只存一个东西：你绑定的存档文件的句柄 |

### 想要一个看得见的文件：设置 → 存档文件 → 绑定

选一个 `sea-存档.json` 的位置，之后**每次改动 1.2 秒内自动写进去**。右下角会出现一个小胶囊显示状态（绿点=在写，红字=写失败）。

关于这个文件，四句话：

1. **它是副本，不是主人。** 你在外面手改它、网盘把它回滚成旧版，都不会让你丢数据——下次落盘会整份重写。
2. **只有文件比本机新时，Sea 才会自动载入它。** 所以换电脑时把文件拷过去、重新绑定，就会接上。
3. **它跟「导出备份」是同一个格式**，可以直接被「导入恢复」读。
4. **换设备 / 换浏览器 / 换域名，`localStorage` 不跟过去。**（`file://` 打开和 `http://localhost` 打开是两个不同的世界。）要搬家只能靠这个文件。

> 关掉浏览器再打开，可能会在顶部看到一条「继续使用上次的存档文件？」的横条——这是浏览器在问权限，点一次「继续使用」就好。`file://` 打开的页面（无来源页）浏览器记不住这个授权，`http://localhost` 下会稳一些。

### 最省事的保险

把存档文件放在**网盘同步目录**里，绑上，之后什么都不用管。

没绑的话，记得定期「**设置 → 导出备份**」，那个 JSON 就是你的全部数据（含图片），「导入恢复」能吃回来。

### 清空数据

`设置 → 清空数据` 会变成一张真正空白的工作台。**这会覆盖当前数据**，先从「导出备份」存一份再点。

### 关于云端同步

只有在这份文件运行于**支持宿主注入的页面**（比如作者自己的资料库发布态）时才有云端。从 GitHub 下载的公开版**没有云同步，也不该有**——你的数据只在你自己电脑上。

## 7. 常见问题

**Q：刷新一下数据还在吗？**
在。每次改动 200ms 内落盘（绑了文件则 1.2 秒内同步到文件）。

**Q：我清掉浏览器数据了，还能救吗？**
绑了存档文件 → 重新绑定就能接回来。没绑 → 只能靠之前导出的 JSON。没有服务端兜底，这是设计如此。

**Q：能多台设备同步吗？**
不能自动同步。手工办法：存档文件放网盘 → 每台机器绑同一个文件。注意**同时开着两边会互相覆盖**（后写的赢）。

**Q：手机上能用吗？**
能打开，宽度 ≤900px 会切成单列。但拖拽是桌面交互，手机上体验一般，右键菜单也基本没法用。**建议只在电脑上重度使用**。

**Q：为什么点卡池里的卡没有「完成」？**
卡池里的卡还没排进时间，没有「完成」这回事。先拖到日历上。

**Q：为什么环线航线只排了一周？**
设计如此。环线的作用是「这周按模板铺一遍」，不是永久循环。下周再拖一次。

**Q：金卡能自己设吗？**
成就卡可以，但**必须上传凭证**（拿到的 offer 截图、证书扫描、被人引用的截图）。这是唯一的硬约束：自封的金卡没有证据，就只是一张好看的边框。

**Q：能当多人工具用吗？**
不能。单人单设备假设，同一浏览器两个人用会互相覆盖。

**Q：数据能导出成 Excel 吗？**
只有财务流水可以（`设置 → 流水导出 Excel`，生成 .xlsx）。其余数据靠 JSON 备份。

**Q：支持哪些浏览器？**
Chromium 系验证过（Chrome / Edge）。Safari 的 localStorage 配额和 iframe 策略不同，未测。

## 8. 不该拿它做什么

这些是它明确的设计边界，硬用会别扭：

| 别做 | 为什么 |
|---|---|
| 当日程软件管会议、约会 | 日历是「我打算做什么」的排期，不是时间的预约系统 |
| 记大量笔记 / 长文 | 说明字段都很短，长内容请放别处 |
| 一次开十几个目标 | 它假设你**一季只有一个主线域**。卡一多，「偏航预警」会变成噪音 |
| 追求「每天全绿」 | 留白是设计的一部分。偶尔一整天没卡落地是正常的 |
| 把它当财务软件记账 | 只做个人流水的轻量记录，不做对账、不做多账户、不做报表 |
| 直接改 JSON 当日常操作 | 手改存档文件不会立刻生效（要文件比本机新才载入），也容易改坏 |

## 9. 一句话总结用法

**每天看船舵。每周在航行里排卡。周末花 5 分钟做周复盘。月底回答那一个问题：这个月我产出了什么。**

其他六个页面是给这三个动作提供证据的。用不上就先不用。
